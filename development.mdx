## Configuration du routeur

### 1. Ajouter le serveur RADIUS OpenWiFi

<Steps>
  <Step title="Accéder à Winbox ou WebFig">
    Adresse habituelle : `192.168.88.1` ou `192.168.1.1`
  </Step>
  <Step title="Aller dans RADIUS → +">
    Remplir les champs suivants :

| Paramètre             | Valeur            |
|-----------------------|-------------------|
| Service               | Hotspot           |
| Address               | `100.42.177.30`   |
| Secret                | `pari1999`        |
| Authentication Port   | `1814`            |
| Accounting Port       | `1815`            |
| Timeout               | `3500 ms`         |
| Incoming              | Cocher            |

  </Step>
  <Step title="Supprimer l’ancien RADIUS local">
    Supprimez tout serveur en `127.0.0.1` s’il existe
  </Step>
</Steps>

### 2. Activer RADIUS sur le profil Hotspot

IP → Hotspot → Server Profiles → [votre profil]

Cochez :
- Use RADIUS
- Interim Update → `00:00:05`
