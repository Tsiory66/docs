## Configuration du routeur

### 1. Ajouter le serveur RADIUS OpenWiFi

<Steps>
  <Step title="Accéder à Winbox ou WebFig">
    Adresse habituelle : `192.168.88.1` ou `192.168.1.1`
  </Step>
  <Step title="Aller dans RADIUS → +">
    Remplir les champs suivants :

| Paramètre             | Valeur            |
|-----------------------|-------------------|
| Service               | Hotspot           |
| Address               | `100.42.177.30`   |
| Secret                | `pari1999`        |
| Authentication Port   | `1814`            |
| Accounting Port       | `1815`            |
| Timeout               | `3500 ms`         |
| Incoming              | Cocher            |

  </Step>
  <Step title="Supprimer l’ancien RADIUS local">
    Supprimez tout serveur en `127.0.0.1` s’il existe
  </Step>
</Steps>

IP → Hotspot → Server Profiles → [votre profil]

# Importer des tickets depuis Mikhmon vers Mana Zone

Pour gérer vos tickets Wi-Fi, vous devez disposer de :  

- ✅ **Accès à Mikhmon** (connecté à votre routeur MikroTik)  
- ✅ **Compte boutique sur Mana Zone**

---

## 1. Accéder à l’interface Mikhmon

1. Ouvrez votre navigateur et allez à l’adresse de votre Mikhmon :  
   `http://192.168.88.10/mikhmon`  
2. Connectez-vous avec vos identifiants administrateur.

> 💡 **Astuce :**  
> Assurez-vous que votre ordinateur est connecté au même réseau que le routeur MikroTik.

---

## 2. Créer des tickets dans Mikhmon

1. Dans le menu à gauche, cliquez sur **Hotspot**, puis sélectionnez le routeur actif.  
2. Cliquez sur **Generate** ou **Users > Add**.  
3. Renseignez les paramètres du ticket :  

| Paramètre | Description |
|-----------|-------------|
| **Username** | Identifiant du ticket |
| **Password** | Mot de passe du ticket |
| **Duration** | Durée de validité (ex. 1 jour, 1 semaine) |
| **Price** | Prix du ticket (optionnel) |

4. Cliquez sur **Create** ou **Generate**.

> 📌 **Note :**  
> Les tickets apparaîtront dans la liste des utilisateurs (Users).

---

## 3. Exporter les tickets (CSV)

1. Dans la section des utilisateurs, cliquez sur le bouton **Export**.  
2. Choisissez le format **CSV** *(seul le format CSV est accepté)*.  
3. Téléchargez le fichier généré sur votre ordinateur.

> 💡 **Conseil :**  
> Conservez le fichier CSV dans un endroit sûr, il contient toutes les informations de vos tickets.

---

## 4. Importer les tickets dans Mana Zone

1. Connectez-vous à votre compte boutique sur **OpenWiFi**.  
2. Dans le menu, cliquez sur **Ticket** puis choisissez votre site.  
3. Accédez à la section **Importer tickets**. Choisissez le routeur/Wifi zone associés 
4. Cliquez sur **Choisir un fichier**, sélectionnez le fichier CSV exporté depuis Mikhmon.  
5. Validez l’importation.

> 📌 **Résultat :**  
> Les tickets seront ajoutés à votre site et visibles dans la section **Tickets**.
