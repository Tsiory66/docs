## 1. Créez votre première **WiFi Zone** (Hotspot)
C’est l’identité de votre point d’accès. Chaque zone = un routeur ou un lieu physique.

### À remplir :
- **Nom de la zone** : ex. `Café Soa - Ambohimanarina`, `Hôtel Le Palmier - Nosy Be`
- **Adresse IP ou DNS du portail captif** :  
  → Exemple : `192.168.1.1`, `hotspot.cafe.mg`, `openwifi.local`  
  *(C’est l’adresse que vos clients verront quand ils se connectent)*
- **Emplacement physique** :  
  → Activez la géolocalisation ou saisissez manuellement (rue, quartier, ville)

## 2. Créez vos **tarifs** personnalisés
Définissez combien vos clients paieront pour accéder à votre WiFi.

### Champs obligatoires :
| Champ | Exemple |
|------|--------|
| **Nom du tarif** | `1h Express`, `Journée Illimitée`, `Pack Étudiant Nuit` |
| **Durée** | `1 heure`, `24 heures`, `Illimité (jusqu'à 23h59)` |
| **Prix** | `500 Ar`, `2 000 Ar`, `1 500 Ar` |
| **WiFi Zone associée** | `Café Soa - Ambohimanarina` |

> Astuce : Créez un tarif **"Gratuit 5 min"** pour attirer les clients !

![Création d’un tarif](https://openwifi.mg/assets/quickstart/tarif-create.png)

---

## 3. Importez vos **tickets WiFi pré-générés** (optionnel mais puissant)
Générez des codes d’accès imprimables pour vendre **hors connexion**.

### Comment faire :
1. Sélectionnez votre **WiFi Zone**
2. Choisissez un **tarif**
3. Indiquez le **nombre de tickets** (ex. 50)
4. Téléchargez en PDF → imprimez → vendez !

> Idéal pour les marchés, taxibe, écoles, événements

![Génération de tickets](https://openwifi.mg/assets/quickstart/tickets-generate.png)
![Ticket imprimé exemple](https://openwifi.mg/assets/quickstart/ticket-sample.jpg)

## 4. Intégrez la **page de paiement OpenWiFi** dans votre portail captif

### Deux méthodes simples :

#### Méthode 1 : **Lien global de la WiFi Zone** (recommandé)
→ Copiez le lien dans **WiFi Zone → "Lien de paiement global"**  
→ Collez-le dans votre portail captif (MikroTik, OpenWrt, TP-Link, etc.)

> Tous les tarifs s’affichent automatiquement

#### Méthode 2 : **Liens directs par tarif**
→ Dans chaque tarif → cliquez sur **"Copier lien direct"**  
→ Intégrez un bouton par tarif dans votre page d’accueil
